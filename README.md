# Evolution of the Internet

## Overview

Evolution of the Internet is a cinematic, scroll-driven storytelling website tracing the internet's history from ARPANET in 1969 to the Web3 + AI era of today. Each of the five eras — ARPANET, Dot-Com, Social Media, Mobile Web, and Web3 + AI — has its own distinct visual identity, from green terminal text to Windows 95 chaos to neon cyberspace.

## Live Demo

https://evolutionoftheinternet.netlify.app/

## Features

- Scroll-driven cinematic storytelling across 5 internet eras
- Era-specific visual themes (terminal green, Windows 95, social blue, mobile gradient, neon Web3)
- Live HUD showing year and era per zone, with dynamic color shifts
- Section navigation dots with era labels
- Era-specific animated elements: Matrix-style code rain, floating Windows-style windows, floating reaction emojis, neon data particles
- Letterbox cinematic framing and scroll progress bar
- Smooth GSAP-powered text and element reveals
- Fully responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GSAP (with ScrollTrigger)

## Installation

1. Clone the repository.
2. Open `internet.html` in your browser.
